# v0.3.1

Range: `v0.3.0`..`v0.3.1`.

## toolchain

- `scripts/appimage`: the AppImage type2 runtime is downloaded with the host's `curl` run as `env -u LD_LIBRARY_PATH curl`; inside `nix-shell`, `LD_LIBRARY_PATH` (`shell.nix` `runtimeLibs`) handed it nix's glibc 2.44 `libdl.so.2`/`libpthread.so.0` against the runner's libc (`GLIBC_ABI_DT_X86_64_PLT` not found), so the v0.3.0 release job built the binary but never published the AppImage.
- First release published through CI: `.github/workflows/ci.yml` job `release` uploads the artifacts of jobs `appimage` and `packages` with `tag-changelog/v0.3.1.md` as notes, after checking the tag is `v` + `[workspace.package] version`. v0.3.0 has no GitHub Release; its changes ship in this one.
- aarch64: job `appimage` builds once per architecture (`ubuntu-24.04`, `ubuntu-24.04-arm`); `scripts/appimage` keys the loader (`ld-linux-x86-64.so.2` / `ld-linux-aarch64.so.1`), the AppRun's multiarch library dirs, the type2 runtime (`20251108`, both SHA-256 pinned) and the file name on `uname -m`, publishing `Decanter-aarch64.AppImage` next to `Decanter-x86_64.AppImage`. `shell.nix` sets `CARGO_TARGET_<host>_RUSTFLAGS` with the host's FHS loader and adds `umu-launcher` on x86_64 only; `Galaxy64.dll` is still cross-built on either host by `pkgsCross.mingwW64`.
- Native packages: `scripts/packages` wraps the AppImage's `AppDir` with nfpm (nixpkgs, 2.47.0) as `decanter_<v>-1_{amd64,arm64}.deb`, `decanter-<v>-1.{x86_64,aarch64}.rpm` and `decanter-<v>-1-{x86_64,aarch64}.pkg.tar.zst`: `AppDir` under `/opt/decanter`, `/usr/bin/decanter` -> `/opt/decanter/AppRun`, `decanter.desktop` in `/usr/share/applications`, the icon at 256x256 in `hicolor`, no dependencies. Self-update stays AppImage-only (`APPIMAGE`).
- CI: job `check` runs Rust stable (fmt, clippy), beta (`continue-on-error`) and the MSRV (`cargo check --workspace --all-targets`); `[workspace.package] rust-version = "1.95"` (gpui at the pinned zed rev uses `std::hint::cold_path`). Job `smoke` runs `scripts/smoke` on `ubuntu-24.04`/`ubuntu-26.04` runners of both architectures and, with `--packages`, in `ubuntu:24.04`, `debian:stable`, `fedora:latest` and `archlinux:latest` (x86_64 only) containers: AppImage `--appimage-extract-and-run --help`, then install with apt/dnf/pacman, `decanter --help`, remove.
