# v0.3.1

Range: `v0.3.0`..`v0.3.1`.

## toolchain

- `scripts/appimage`: the AppImage type2 runtime is downloaded with the host's `curl` run as `env -u LD_LIBRARY_PATH curl`; inside `nix-shell`, `LD_LIBRARY_PATH` (`shell.nix` `runtimeLibs`) handed it nix's glibc 2.44 `libdl.so.2`/`libpthread.so.0` against the runner's libc (`GLIBC_ABI_DT_X86_64_PLT` not found), so the v0.3.0 release job built the binary but never published the AppImage.
- First release published through CI: `.github/workflows/ci.yml` job `appimage` uploads `Decanter-x86_64.AppImage` with `tag-changelog/v0.3.1.md` as notes. v0.3.0 has no GitHub Release; its changes ship in this one.
