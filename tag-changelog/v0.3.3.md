# v0.3.3

Range: `v0.3.2`..`v0.3.3`.

## Windows (testing)

- `decanter_core::platform::windows::support`: `Play`, `ExternalInstaller` and `GalaxyHook` (x86_64) go from `Testing` to `Available`; `Tray`, `CloseToTray` and `PadClose` are `Testing`. macOS: `Tray` and `CloseToTray` `Testing`. `Feature::ALL` 18 -> 20 with `PsKeyStick` and `PsOnline`, unavailable on both.
- Frame: `platform::NATIVE_FRAME_CONTROLS` (Windows `true`) makes `views::chrome` ask for a transparent title bar and drop the resize edges, leaving drag, minimize, maximize and snap layouts to the OS hit-test (`window_control_area`).
- Sessions: `decanter_runtime::native` joins the launched process to a Job Object (`win32job` 2.0.3, `join_job`; no kill on close, so a game outlives a crashed decanter). `Session::wait_status` returns once the job is empty (`outlive_launcher`, `JOB_POLL_INTERVAL = 1 s`); `stop` sends `taskkill` to every pid in the job (`Tracked::pids`), polite first then forced as before. Without a job (no handle, create or assign failed) it follows the launched process alone. A process started before the job assignment escapes it (`NOTE` in `join_job`).
- Tray: `tray-icon` 0.26.1 (`muda` 0.21.2) in `app/src/platform/system_tray.rs`, built on GPUI's main thread; `platform::{spawn_tray, refresh_tray}`. Linux keeps `ksni`. `status_notifier_host` is always `true` on Windows.
- Close-game shortcut: `global-hotkey` 0.9.0 in `app/src/platform/close_hotkey.rs`, Ctrl+Shift+F4 (`Modifiers::CONTROL | Modifiers::SHIFT`, `Code::F4`) while a game runs; `CLOSE_GAME_LABEL` and `CLOSE_GAME_HINT` name it. No pad chord and no notice on Windows.
- System language: `platform::system_locale` reads `LC_ALL`, `LC_MESSAGES`, `LANG` on Linux and `sys-locale` 0.3.2 on Windows and macOS (a program started from the desktop has no `LANG`).
- Task bar identity: `platform::set_app_identity` calls `App::set_app_identity("decanter", "Decanter")` (GPUI at zed `8fda6e4`) from `main`; no `unsafe`. No-op on Linux and macOS.
- `.github/workflows/ci.yml`: the Windows job's `decanter.exe` is downloaded by the `release` job (`needs: [smoke, check-other]`, `!cancelled() && needs.smoke.result == 'success'`) and attached as `decanter-<version>-windows-x86_64.exe` when built.
- `hostname()` reads `COMPUTERNAME` on Windows (debug log subfolder).

## app

- Debug mode (`debug_logs`): settings `debug_mode` (`1`/`0`) and `debug_log_dir` (default `<library>/decanter/logs/debug`), toggled in Ajustes > General. decanter's session log and each job log go to `<folder>/<host>/` as `.partial`, renamed when whole (`debug_logs::complete`, `logs::close` at a clean exit); `SESSIONS_KEPT = 20`, `JOBS_KEPT = 50`. PS runs get `PS_DEBUG=1` and `PS_DEBUG_DIR`, also per game (`titles.<TITLE_ID>.debug`, `TITLE_KEY`).
- Cache location per library folder (`decanter_core::cache`): table `library_caches (folder, cache_path)`, default `<library>/decanter/cache`; `shader_cache_env` sets `MESA_SHADER_CACHE_DIR`, `__GL_SHADER_DISK_CACHE_PATH` (with `__GL_SHADER_DISK_CACHE=1` and `__GL_SHADER_DISK_CACHE_SKIP_CLEANUP=1`), `DXVK_STATE_CACHE_PATH` and `VKD3D_SHADER_CACHE_PATH` under `<cache>/<group>/<id>` unless already set; PS runs get `PS_CACHE_DIR`. `Db::rebase_library_caches` follows a moved folder.
- Sizes: `InstalledGame::size_fingerprint` (manifest key `SizeFingerprint`) and table `dump_sizes (dir, size, fingerprint)`; `decanter_core::install_fingerprint` decides whether external games and PS dumps are measured again (`app/src/dump_size.rs`). PS dumps live in `<library>/psport/games` of any of the profile's folders (`decanter_ps::paths::games_in`).
- i18n: translated texts are kept as `i18n::Text` and translated when drawn, so a language switch updates notices and errors already shown. `app/locales/<lang>/*.<lang>.yml` replaces the one-file-per-area layout; `_language.<lang>.yml` carries `language.native_name`, and the language list and system match come from `rust_i18n::available_locales!()`.
- `Caps` `NeedsSetup` reasons are translated through `setup_text` (`common.setup.*`).
- CI: `.github/workflows/antispam.yml` on `issues` and `issue_comment`: skips `OWNER`, `MEMBER`, `COLLABORATOR`, `CONTRIBUTOR`; strong signals (`iex(irm ...)`, obfuscated `iex`/`irm`, `curl|wget ... | sh`, `BAD_DOMAINS`, `.sbs/.top/.xyz/.click` URL in an execution context) hide a comment (`minimizeComment`, ABUSE) or label `spam`, close and lock an issue; weak signals only notice. `DRY_RUN = "false"`.

## desktop

- `decanter_core::steam::process::state` returns `SteamState::{Running, NotRunning, Unknown}`: `/proc` scan first, then a non-blocking write-open of `.steam/steam.pipe` (`ENXIO` = no reader), found in the nearest ancestor of the Steam root holding `.steam`; an absent or non-FIFO pipe is `Unknown`. `wait_for_exit` waits until `NotRunning` (`SHUTDOWN_TIMEOUT = 60 s`); `Unknown` keeps the change staged until the user confirms. Outside Linux the pipe probe answers `NotRunning`.

## gog

- `decanter_gog::session::{check_session, renew_session}` (`SessionState::{Valid, Closed, Unreachable}`) replace `gog::session`: HTTP status decides, `401`/`403` (and `400` on the token endpoint) are `Closed`, any other failure `Unreachable`; the refresh goes to `https://auth.gog.com/token` and is stored at once.
- `with_session` persists the token the `gog` crate refreshed even when the call fails, and only when it changed.
- A closed session leaves the library on its cache with no error; `views::session_renewal` offers renewal once per closing (refresh token first, then the browser login, which must land on the same account); Ajustes > Cuentas has Renew beside Log out.

## ps

- Online (decision #715), offered once `--list-features` lists `online_module` (`Feature::PsOnline`): launch settings `online`, `online_server` (default `play.seamlesshunt.com:31313`), `online_webapi`, `online_community` (default `http://play.seamlesshunt.com`), `online_npid` (3 to 16 of letters, digits, `-`, `_`; not an email), `online_upnp`, `online_bbsc`, `online_bbsc_local_server` (`0`, `1`, `auto`), checked in `bbport::online` before they become `run.sh` variables. Password and token live in the keyring as `shadnet/<NPID>/{password,token}` (`ShadnetSecret`); `LauncherSettings::load` and `save` drop `online_password`. Views: `views/ps/online.rs` (Ajustes), `views/ps/games/online.rs` (Bloodborne's Online tab).
- Settings in the built-in table: `effect_bloom` (default on), `keep_logs` (0 to 200, default 30), `camera_cuts`, `image_traps`, `aniso`, `pad_motion`, `toypad`, `intel_tonemap` (`""`, `1`, `0`), `upscaler` option `dlss`, the system fonts folder (`views/ps/settings.rs`, optional, the user's own dump). Shown defaults now follow psport's: `upscaler` `fsr3` (was `fsr4`), `preset` `0` (was `4`), `sharpness` `0.3` (was `0.5`), `show_fps` off (was on).
- Keyboard group (`key_stick_opposite` `last`|`neutral`, `key_stick_hold_ms` 0 to 200 step 10, default 60, `zero` label "no hold") is shown only when `--list-features` lists `key_stick` (`Feature::PsKeyStick`).
- `bbport::OPTION_FEATURES`: `upscaler_fsr4`, `upscaler_fsr411`, `upscaler_dlss`, `intel_tonemap_fix`; rows psport marks unavailable in the areas `upscaler` and `cpu` hide that option (`HostFeatures::unavailable_options`, `Caps::ps_hidden_options`).
- `bbport::effects::list` runs through `query_port` (`QUERY_TIMEOUT = 30 s`, `MAX_ANSWER = 64 KiB`), like the feature and online queries.
- Testing channel: `prebuilt::lookup` of `commit-<sha>` for a clean upstream checkout; builds locally otherwise and never replaces a build over local changes.
- Vulkan validation layer on demand (`toolchain::validation`, `state::ps::vk_layer`): the launch realises `vulkan-validation-layers` from the pinned nixpkgs (`validation.nix`) rooted at `<toolchain>/vulkan-validation/<toolchain id>`, passes `VK_ADD_LAYER_PATH`; when it can't (`Unavailable::{NoNix, Setup, Build}`) the validation variable is dropped, the notice, the run's facts and the log say why. New job kind `JobKind::VkLayer` (`vk-layer`).
- Saving `settings.json` drops `MEMORY_MODEL_SETTINGS` (`pc_model`, `preupload`, `as_0_3`) once the checkout's `run.sh` ignores them (`single_memory_model_blocking`); older ports keep them.
